## 5. The actual common neighbor C has no separating axis

Take its real contacts T_B in B intersect C and T_D in D intersect C.
They may be any original application points; coincident physical
junctions are included. C has disjoint open interior from H, so
one own side axis of H or C separates the two closed squares.

No H coordinate axis can do so. A C entirely left or below H
misses B by (15); a C entirely right or above H misses D by
(11)--(12). Thus an actual own unit axis n of C separates it
outward from H.

If both components of n are nonnegative, every point of D has
strictly smaller n projection than H's northeast corner, by
(11)--(12); it cannot touch C. If both are nonpositive, the same
contradiction at B follows from (15) and H's southwest corner.
Only the two strict mixed-sign directions remain.

For a northwest separator write n=(-c_0,t_0), with c_0,t_0>0
and c_0^2+t_0^2=1. Put the coordinate origin at H's northwest
corner (-A,h), and let k=(t_0,c_0), C's other own unit axis.

    -c_0 Delta x+t_0 Delta y>=0.

At T_B, (15) gives Delta x>1/4, so its k-coordinate is
greater than 1/(4t_0). At T_D, (12) gives Delta y<-49/100,
so its k-coordinate is less than -49/(100c_0). C would therefore
need an own-axis projection width greater than

    1/(4t_0)+49/(100c_0) >1.                            (16)

Indeed Cauchy--Schwarz gives the lower bound
(1/2+7/10)^2/(t_0+c_0)>=36/(25 sqrt(2))>1.
But an actual unit square has own-axis width exactly one.

For a southeast separator write n=(c_0,-t_0) with the same positive
parameters and put the origin at H's southeast corner (epsilon,h-1).

    29/(30c_0)+11/(15t_0)>29/30+11/15=17/10>1.

This is the same unit-width contradiction. Every separating axis
has been excluded. Thus no actual C can touch both B,D while
avoiding H. This proves the complete aligned-root theorem, including
