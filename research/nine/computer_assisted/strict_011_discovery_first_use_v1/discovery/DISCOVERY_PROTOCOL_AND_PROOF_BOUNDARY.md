# First standalone numerical protocol for strict 011/00

This discovery entry uses only the frozen rebuilt representative root,
its physical row factory, independent exact adapter, generic rational
arithmetic, and complete 4/8/2 cover constructors. No registered 001 cell,
legacy V/K initializer, original-cell context, or extra affine row family
is imported. The mask and strict-radius caller are fixed by the complete
root document and the source-pinned 184-file checkpoint.

## Numerical proposals and exact acceptance

Floating-point linear programming is imported lazily, only by the real LP
backend. Single-thread BLAS/OMP settings are required before that import.
The phase problem minimizes one nonnegative relaxation variable applied
to every existing affine row. An optimal LP status by itself proves
nothing. Its dual values suggest nonnegative rational row weights at
denominator `2^40`.

For a proposed contradiction, the driver recomputes the weighted exact
row sum. If its original/auxiliary coefficient residual is c and the
same physical state has certified absolute variable bounds B, the reserve
is `-weighted_rhs - sum(B_i*|c_i|)`. It must be strictly positive. The
frozen independent reserve checker reconstructs every used physical row
and verifies the exact weights and reserve before the record is saved.

For a proposed upper bound on a scalar or a pair difference, the selected
objective is subtracted from the weighted coefficient sum. The same exact
residual payment yields a rational upper bound. It is rounded outward to
the frozen `2^-20` grid and accepted only when it improves the inherited
interval. The independent round checker reconstructs all printed rows,
checks the residual payment, and verifies the exact state transition.
Every printed row is used and every used row is printed.

The numerical point only chooses subsequent complete splits. Unit-frame
normalization in that heuristic grants no constraint or proof credit.
Proxy choices come in all four signed coordinate alternatives; owned SAT
choices come in all eight owner/axis/sign alternatives; angle splits keep
both closed halves. Budgets stop with explicit OPEN alternatives, never
an omitted part of the physical domain.

## Durable complete frontiers

Each node record has an immutable content-addressed filename. Updating a
node writes a new record; it never changes a record named by an existing
manifest. All pending siblings are written before the manifest names a
new split. The only mutable proof pointer is `manifest.json`, written
through the accepted atomic JSON helper. Each manifest version references
only already-written, hash-checked records and a complete closed cover.

If a record or manifest write fails, the exception propagates out of the
actual driver. Previously installed records and manifest versions are
not deleted. If the failure happens after manifest replacement, the new
manifest still references the complete new set of immutable records.
Unreferenced partial/new records remain as provenance and may be ignored
by the exact complete-tree checker. This is a proof-pointer construction;
it does not change the atomic helper into a multi-file transaction or
promise hardware durability beyond its recorded fsync operations.

An input frontier is freshly checked before any LP or output mutation.
The final complete frontier is replayed in a separate `python -B -S`
interpreter with packet-local exact dependencies and no numerical imports.
Only that exact report can establish a complete tree, and no discovery
completion automatically changes a mask ledger.

## Staged first actual use

The small exact controls replace the LP backend with explicitly selected
rational dual proposals. They verify a real four-row conditional exclusion,
a three-row bound, altered-dual rejection, and five interruption windows
through the actual discovery/manifest code. They are not an actual LP run
and cannot satisfy the first numerical gate.

For deterministic write-failure injection those controls reuse the same
already hash-checked bootstrap bundle; no source, row factory, state, or
exact arithmetic is replaced. Separate store controls independently replay
all eight H/I owned alternatives and both D-angle halves produced by the
new manifest writer. The first real LP run remains explicitly pending.

After source review and a free authorized numerical slot, run the real
LP phase only on the AB negative-x inset alternative. The driver first
creates the entire four-way proxy cover, then attempts that one child.
Its final exact report must have five nodes, one excluded leaf, three
OPEN leaves, and no whole-mask claim. The other alternatives remain
explicitly preserved.

Only after that real weighted-use gate passes, begin a separate bounded
whole-root run from the fresh complete root. The initial proposed budget
is one bound round per visited node, 54 objective proposals per round,
33 total nodes, and depth eight. These are discovery limits, not omitted
proof domains. More rounds or later continuation require the same source
and whole-frontier checks.

No actual LP has been called by source preparation or its exact controls.
No conditional actual-AB theorem is installed. The first numerical gate
and a broader OPEN run remain separate, reviewable next actions.
