# Complete ancestry for the strict 011/00 C-height union

This version adds one separately named union kind to a copy of the reviewed
strengthened complete checker. It does not edit the accepted foundation,
4/8/2 checker, numerical driver, or any active tree. Its first actual global
height-cover use remains held until independent source review and fresh
scalar replay. The preparation contains local conditional arithmetic and
candidate trees, not a claimed successful height-cover replay.

## Physical caller and theorem cover

The root document is exactly the accepted representative of the full strict
`011/00` caller, with all nine physical originals, all 36 corners, all 36
interior-disjoint pairs and all five exact marked links. AB, EF and FG are
actual links; BC and CD retain their strict weak bit relations. The whole
caller is normalized only by the reviewed vertical reflection and H/I swap.
All shared zero faces remain. There is no inherited 001 cell path, actual-BC
assumption, D/G corridor, or closed-Q equality blocker.

The frozen C-height design `06aba6fc...` uses the accepted original-C
seven-square theorem. The BC/CD center cones give `x_B <= x_C <= x_D`.
If `W_C=|y_C-y_B|+|y_D-y_C| <= 21/100`, that theorem proves
`q >= 1105/256`, contradicting the strict caller. Thus every physical caller
has `W_C > 21/100` and belongs to at least one of the four closed alternatives
from that design. This consequence remains valid after any earlier ordinary
proxy, owned-axis or angle restriction.

The new complete checker reconstructs the complete four-form literal from the
frozen independent design. It requires all four distinct branch numbers and
four distinct child nodes. A first accepted height union starts the full
accepted scalar checker in a new directory, with the prescribed 28 domains,
351 leaves and 43,875 Bernstein coefficients. An existing output directory or
an old report cannot satisfy this gate. No child of that union is replayed
before the fresh scalar gate returns successfully.

## Base state and domain context are separate

All original state dictionaries retain exactly the old keys, coordinate
boxes, canonical angle intervals, original differences and ordinary 4/8/2
path syntax. There is no path stripping, state widening or hidden new field
inside that mathematical state.

Each record has an additional envelope field `height_context`. The root must
have exactly JSON `null`. A height union's child keeps a byte-equivalent
serialized copy of its parent's certified final base state and receives one
context containing:

- the distinct height-domain kind and fixed design binding;
- the exact root-document hash;
- the originating union node;
- the canonical hash of that node's certified final base state;
- exactly one integer branch in `{0,1,2,3}`.

The context denotes conjunction with the selected closed height halfspace.
The child box is not narrowed merely because a branch has been selected.
Later exact row deductions may narrow it. The parent final-state hash is
computed after independently replaying the parent's complete record; a
serialized proposed state is not accepted as that parent.

At every node, internal node and leaf, the checker compares the record's
envelope with the context reconstructed by the ancestor traversal. The
adapter receives this checker-owned expected context. It never obtains its
authority by reading a free context from the record. An originating node,
parent hash, branch or caller mismatch is rejected. Missing contexts are also
rejected, including at ordinary descendants. A second height union on an
already selected height path is forbidden in this version.

## Induction through the complete tree

At the root, any physical caller realizes the exact reviewed root state and
the empty context. Assume a physical caller lies in a node's base state and
context. Independently replayed bounds preserve its membership, and a proved
terminal excludes it using the rows valid on that same domain.

For an ordinary proxy, owned-axis or angle union, the accepted child
constructors and complete closed alternative sets are unchanged. The height
context is inherited exactly, so conjunction with that context preserves the
ordinary coverage proof. The old SAT/proxy/angle dispatch is AST-identical to
the reviewed checker. Both sides of every closed angle cut and all ordinary
shared boundary faces remain present.

For a height union, the physical caller satisfies the full strict caller and
therefore one of the four closed height alternatives. Each child keeps the
exact parent base state and adds its selected context. The source theorem
does not require the parent box itself to be covered as an arbitrary relaxed
LP box. Completeness concerns physical callers, as justified by the freshly
replayed theorem. The new union cannot be relabeled as an ordinary proxy.

The traversal checks every child without short-circuiting, forbids reused or
cyclic nodes, and requires the visited set to equal the declared node set.
The edge count now adds four edges for each height union; the old 4/8/2 counts
are unchanged. All leaves must be excluded for a whole-mask conclusion. This
preparation makes no such conclusion.

## Conditional row reconstruction

The context adapter delegates all existing rows, variable bounds, propagation
and terminal checks to the reviewed strengthened adapter. It partitions out
only the distinct height-row prefix. The selected height row is reconstructed
from the fixed independent four-form literal and must match its complete
printed coefficients, name and `-21/100` right side. It is rejected without a
selected context and rejected in any other selected branch.

The row uses only the original y coordinates, columns 3, 5 and 7. No new
variables, corner formulas, SAT products or numerical assumptions are added.
Printed indices remain unique. The original exact residual and bound-grid
checks apply without modification. Existing theorem guards can use the
certified base bounds derived within the height domain; the enclosing
record's context supplies their full ancestry. Their separate fresh-scalar
gate remains unchanged.

Local arithmetic under an explicitly assumed height halfspace can be checked
without invoking the global coverage theorem. That conditional check is not
a complete-caller proof. In the full checker, the empty root context and the
freshly gated ancestor union are what justify using the halfspace at a
descendant. `assert_active_context` enforces this distinction before each
nonempty-context record is replayed.

## Fresh discovery attachment and atomicity

The separate discovery attachment has no LP entry and no arbitrary-tree
resume API. A fresh store creates the exact whole root and keeps its own
expected initial states and contexts, derived from its constructors. It
checks them against every record before a local update. A future resume
attachment must reconstruct them through the complete checker.

Ordinary split operations call the accepted atomic `Store.split` unchanged,
using a locally constructed adapter and inserting the fixed inherited
context before each immutable child record is written. The new height split
constructs all four children, writes all immutable records, and then uses the
same accepted atomic manifest replacement. The in-memory context map changes
only after that replacement succeeds. An injected ENOSPC leaves the old
whole-root manifest and its exact replay valid, even when unreferenced child
files have already been written.

The discovery attachment may prepare candidate partitions and conditional
certificates. It cannot declare that a full caller is covered. The separately
versioned complete checker and fresh scalar gate remain mandatory before any
global height-cover acceptance.
