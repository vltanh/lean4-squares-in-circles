# Independent review of the prepared full strict 011/00 root

The proposed caller and its elementary affine specification pass this review.
This is a review of an uninstalled design, not acceptance of a new geometry
adapter, a numerical certificate, or a mask closure. The accompanying JSON
pins every inspected source and records an independent literal reconstruction
of all 159 prepared rows without importing the producer or the old geometry.
The repository-path copy of the strict-terminal publication manifest was
absent in this checkout; the review explicitly uses its byte-identical staged
publication copy, matching the same pinned SHA256. The JSON records that sole
source-path relocation. No source or mathematical byte was changed.

## Physical caller and complete covers

The caller retains all nine original squares, their 36 corners and 36 pairs,
the five directed center cones, actual AB/EF/FG projection separation and
strict reverse BC/CD comparisons. A common rotation fixes the witness axes
and preserves the centered disk. Each square may then choose its own quarter
turn parameterization with alpha >= abs(beta); this preserves the physical
square and both closed canonical diagonal faces. No translation, original
001/00 path, endpoint sign, DG corridor, CD gap or H/I ordering is introduced.

The generic emitter's corner scaling is exact: its X,Y equal twice the
physical corner coordinates, so 64(X^2+Y^2)<1105 is precisely the strict
radius predicate. For each pair, both signs of all four owned axes are
included. On each axis the sum of physical halfwidths is
(1+abs(C)+abs(S))/2; the four sign inequalities implement this maximum.
Contact remains allowed. The prepared specification enumerates the same
36 pairs and all eight alternatives for each pair. Future angle and proxy
splits still require their independently reconstructed complete closed unions.

## Initial boxes and elementary rows

Canonical unit frames give alpha^2 >= 1/2 and beta^2 <= 1/2, hence the
proposed rational alpha, beta and absolute-beta intervals are outer bounds.
Also 1 <= alpha+abs(beta) <= sqrt(2) < 3/2, so the physical inset halfwidth
g=1/(2(alpha+abs(beta))) lies in [1/3,1/2]. Averaging the four squared corner
norms gives norm(c)^2+1/2 < 1105/256; each center coordinate is therefore
inside [-2,2]. The initial path, selected pairs, difference map and diagonal
map are empty. No inherited original-specific interval has been substituted.

The literal review reconstructs 108 bound rows, 36 frame consequences,
10 cone rows and five mask rows. BC/CD retain the strict source relation
even though their necessary affine rows use its weak relaxation. A future
terminal cannot replace that strict caller by the relaxed LP predicate.

## Optional universal center bound

The separate stronger center bound is physically valid even under closed
disk containment. If r=norm(c), orthonormality yields

    max_corner_norm_squared
      = r^2 + 1/2 + abs(c dot u) + abs(c dot v)
      >= r^2 + r + 1/2.

The last inequality follows by squaring the nonnegative quantities and
retaining the nonnegative cross term. At rho=91/60, the right-hand side
exceeds 1105/256 by exactly 31/57600. Since r^2+r+1/2 is increasing on
r>=0, r<rho. Thus [-91/60,91/60] is a valid closed coordinate enclosure
for each original square, independent of mask and labels. The prepared root
still uses [-2,2]; this review installs no new row or bound.

## Reuse boundary and remaining implementation work

The source design correctly excludes the old V/K initialization stack.
Those functions contain unconditional 001/00 restrictions even when given
an empty path. Generic arithmetic and universal local row identities can
be reused only behind a fresh independent geometry adapter, with this
caller's own intervals, chosen products, absolute bounds and terminal guards.
In particular the strict 011 terminal must use its published strict caller
attachment; the 001 closed-Q equality blocker is not inherited.

No optimizer, full tree replay, Lean, Lake or CI was run for this review.
The proposed adapter, local row controls, strict caller attachment and first
weighted physical replay remain future implementation gates. No original
or mask status changes follow from this design review.
