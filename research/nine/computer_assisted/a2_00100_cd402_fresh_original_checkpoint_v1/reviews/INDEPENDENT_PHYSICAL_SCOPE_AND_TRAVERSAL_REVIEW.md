## Caller and parent attachment

The tree checker pins both the whole-original bound certificate and its
independent checker. It constructs the original state again through
`ORIGINAL.check_declaration`, including the exact original identifier, path,
registry hash, canonical frames, all nine originals, the 36 corner and pair
predicates, five marked cones, and fixed `001/00` links. It then replays all
three bound rounds using the frozen rational record checker before exposing
the resulting state to the tree.

It does not trust a serialized final state or an OPEN-state report as a proof
premise. The parent reference must equal the pinned whole-original certificate,
and the reconstructed final identifier and path must remain those of Cd402.
The new seed is a literal zero-round identity record on that final state.
Its only node is the root, with no restriction, no children, and OPEN status.

The continuation uses the fresh Cd402 context. Its explicit source adaptation
removes the C887 union argument and all C887 height-consequence attachments.
The exact checker rejects component-specific and other-original consequence
fields and uses the unchanged general physical adapter. The Cd402 original
path and closed shared faces are retained, including the three branch-2
alternate rows reviewed with the original initializer.

## Complete closed unions

Every node record is replayed from the state independently reconstructed for
that node. A proved terminal must be a childless candidate exclusion. An OPEN
leaf remains an unproved domain and prevents a whole-tree exclusion.

For a proxy union, the checker validates the ordered pair of distinct original
labels and requires exactly the four axis/sign alternatives. For a physical
separating-axis union, it requires exactly the eight owner/axis/sign
alternatives using the two actual original squares. Restrictions must match
the parent pair and have the exact expected keys and integer choices. The
existing independent proxy and separating-axis child constructors supply the
children; no new geometric union rule is introduced.

An angle union requires exactly two restrictions on one of the nine original
canonical angles. The cut is rational and strictly inside the parent's angle
interval. The children contain the shared cut face on both sides. Their paths
and reconstructed choices are checked again through the normal adapter.

The visited-node set must equal the entire manifest node set. Duplicate
children, repeated visits, missing alternatives, orphan nodes and incorrect
parent/depth/restriction data are rejected. Every internal status is checked
against the conjunction of its children's independently computed outcomes.
The root report claims a complete whole-original exclusion only when this
recursive conjunction is true. All referenced inputs are rehashed afterward.

## Storage and numerical scheduling

The exact checker keeps node metadata but reads each record payload lazily,
discarding a parent's payload before descending. This changes storage rather
than arithmetic. Physical rows, residual payment, accepted terminals and
source bindings remain those of the frozen `ALL`, `SAT` and `PROXY` modules.

The numerical continuation copies old records, retains all completed rounds,
and concatenates new rounds only to OPEN leaves. It creates every child of a
new union before traversing any child; unvisited siblings are explicit
zero-round OPEN records. Its exception paths retain a partial candidate cover
and do not establish an exclusion.

The per-completed-round angle callback receives the exact engine object `E`
from the Cd402 context. Its phase and bound calls therefore use that runtime's
patched state serialization and active solver objects. It checks already
computed phase points and introduces no proof premise from the optimizer.
The frozen exact traversal remains the acceptance gate regardless of the
chosen numerical budget, split order, or candidate status.

The explicit source transformation reproduces the delivered driver byte for
byte, with each old text fragment occurring exactly once. No physical row or
proof rule changes in that transformation. No original-cell or mask credit is
added by this review.
