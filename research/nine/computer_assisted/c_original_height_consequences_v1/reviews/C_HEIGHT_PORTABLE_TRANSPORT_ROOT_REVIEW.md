## Input and mathematical identity

The materializer verifies the thin delta's complete inventory, both frozen
base manifests, every selected base member and every assembled input. A
preexisting overlap is accepted only when its bytes have the same hash.
Resolved source and destination names must stay inside their declared
roots. The original base packets are not changed.

The launcher hashes raw mathematical and checker bytes before and after
replay. Its JSON facade maps only whole string values that exactly match
an inventoried filename or directory alias. Dictionary keys are mapped
only for explicit file aliases. The mapping is injective and rejects
collisions. Unknown names, embedded path strings, predicates, original
indices, coefficients and rational endpoints are unchanged. No physical
configuration or arithmetic input is inferred from a path translation.

This reference transport lets the frozen checkers compare their relocated
file-relative bindings to the same references in their manifests. The
source byte hashes themselves remain hashes of the original raw files.

## Isolation and legacy outputs

Every exact child re-enters the same launcher with the same interpreter,
`-B -S`, and an explicitly inventoried Python script. Numerical imports
are forbidden. The audit checks both lexical and resolved paths. Packet
reads must be inventoried; every packet write and filesystem mutation is
forbidden. Output symlinks must remain within the fresh output root.
External workspace reads are rejected, and bytecode probes are directed
to output while bytecode writes are disabled.

The archived C guards are unchanged. Packet and output roots are under
`/tmp`, so those historical workspace guards can coexist with the
launcher's independently checked packet inventory. The old checkers'
three known diagnostic report directories are routed into fresh output.
Every such directory subtree is required to be disjoint from every
frozen input. This exception redirects diagnostic destinations; it does
not authorize any packet mutation or additional proof input.

Root checked joined `HERE / report_directory / filename` routing in the
actual Python 3.12.14 environment. The publication command should use
Python 3.12; this review makes no portability claim for older pathlib
join implementations.

The first attempt correctly stopped at a missing transitive Python
source. The next attempt correctly stopped at a legacy source-directory
write. Both failed attempts remain diagnostic records, with no claimed
portable arithmetic acceptance. The final revision adds bound published
imports and explicit fresh-output destinations without editing the
mathematical sources or relaxing the packet write guard.
