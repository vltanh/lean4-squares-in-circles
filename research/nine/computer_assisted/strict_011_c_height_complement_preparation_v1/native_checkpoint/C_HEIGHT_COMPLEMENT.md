# Prepared C-height complement for the full strict 011/00 caller

This note proposes a future theorem-dependent complete cover. It does not
change the frozen 4/8/2 checker, the strengthened numerical driver, or any
ledger. Its use still requires the accepted universal scalar theorem to be
freshly replayed and this new cover attachment to be independently reviewed.

## Caller and accepted theorem

Use the entire fresh strict `011/00` caller: all nine distinct physical unit
squares, all 36 corners in a common centered disk with squared radius
`q < Q = 1105/256`, all 36 interior-disjoint pairs, and all five exact marked
cones and bits. In particular AB, EF and FG are actual horizontal links.
The BC and CD cones give `x_B <= x_C <= x_D`. No D-angle sign, D/G corridor,
actual BC, equality blocker, or old 001 path is assumed.

The reviewed C-label application of the universal actual-AB two-link theorem
uses the seven distinct originals A, B, C, D, E, F, G and retains H and I in
the full caller. It proves `q >= Q` if

`W_C = |y_C-y_B| + |y_D-y_C| <= 21/100`.

Consequently every physical configuration of this strict caller satisfies
`W_C > 21/100`. This is a strict-radius conclusion. This note makes no
closed-radius exclusion claim.

Both exact accepted root documents are supported: the unnormalized full
caller and its representative with `beta_D >= 0` and `x_H <= x_I`. The latter
uses the accepted whole-caller vertical reflection and H/I permutation,
including all shared zero faces. Reflection negates all four height forms
and permutes branches 0 with 3 and 1 with 2; it leaves `W_C` unchanged. The
H/I permutation changes none of B, C, D or these forms. Thus the cover is
compatible with that full-caller existence equivalence. It does not transport
any old registered-cell proof or silently add a normalization to a state.

## Exact four-way identity and cover

For real `u = y_C-y_B` and `v = y_D-y_C`,

`|u|+|v| = max(u+v, u-v, -u+v, -u-v)`.

Every signed expression is at most the left side by the triangle inequality.
Choosing the sign of each nonzero coordinate gives equality; at zero, either
closed sign choice works. The four linear forms are therefore

| Branch | Linear form L | Closed complementary domain |
| --- | --- | --- |
| 0 | `y_D-y_B` | `L >= 21/100` |
| 1 | `2*y_C-y_B-y_D` | `L >= 21/100` |
| 2 | `y_B+y_D-2*y_C` | `L >= 21/100` |
| 3 | `y_B-y_D` | `L >= 21/100` |

The independent symbolic checker also verifies this identity without relying
on a finite sample. In each of the four closed sign quadrants it writes
`y_B=w`, `y_C=w+r*a`, `y_D=w+r*a+s*b`, with `a,b >= 0` and `r,s` each a sign.
Every difference `(a+b)-L` has coefficients 0 or 2 on `a,b`, and exactly one
of the four forms has both coefficients zero. The 16 nonnegative residuals
and four attaining identities prove the max identity on all real heights.
The extra rational examples only check implementation and boundary handling.

Because `W_C > 21/100`, at least one form is strictly larger than the
threshold. Thus these four closed halfspaces cover every physical caller.
Their intersections and equality faces are intentionally retained. This is
a cover of the physical strict caller after the accepted theorem; it is not
a claim that the four halfspaces cover an arbitrary relaxed LP box.

Each branch may add the single necessary row `-L <= -21/100` on its own
domain. The coefficients use only the original center coordinates and need
no additional variables. The row has no authority outside its selected
domain. The rejected middle region where all four forms are at most 21/100
is excluded by the fresh universal theorem and complete physical attachment,
not by a numerical proposal or a stored scalar-report header.

## Required future integration

A new explicit branch schema or a separately checked theorem-dependent root
composition must reconstruct all four exact halfspaces, bind the unchanged
root document and scalar sources, and retain every branch. These are not the
ordinary coordinate-proxy alternatives: the frozen 4/8/2 checker must not be
made to accept them by relabeling them as proxies. All descendant arithmetic
would still need same-state literal reconstruction and a complete exact
cover. Until that source/physical review exists, these rows remain a prepared
consequence and are not installed in any search.
