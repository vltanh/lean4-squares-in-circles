# Existing strict-original boundary guard helpers

This package contains immutable source-bound helpers for the existing sharp-row
and all-nine deep-cylinder terminals. It grants no original-cell or cover credit.
A consumer must first independently reconstruct the unchanged registered strict
001/00 original caller, retaining all9 physical squares, all36 corners and pairs,
actual AB/BC/EF/FG, all5 marked center cones and the original strictly weak CD bit.

`original_boundary_guard_helpers.source_bindings()` verifies and returns every
local dependency hash. The bundle is relocatable: mathematical sources and their
recorded hashes remain unchanged. Paths marked `original_path` in provenance JSON
are descriptive; the helper reads only the copied local files.

`verify_sharp_literal(guard, independently_propagated_state, geometry)` uses the
unchanged independent shared-sharp decoder. It checks the original register,
Q and marked bits; the consumer must supply physical intervals reconstructed by
its exact adapter. The accepted AHID row bounds only the seven original angles
A,D,E,F,G,H,I; original B,C remain physical and supply the equality blocker.
The three accepted parameter pairs are (1/30,11/30), (1/50,9/20), (1/200,53/100).
Every row order, positive shoulder gap and height variation guard is still checked.

`verify_deep_literal(terminal, independently_proved_state, geometry)` checks all9
original slopes within1/64, the16 center coordinates other than F within1/64 of
the listed base, and freshly replays all144 signed-angle identities before first
acceptance. Both F center coordinates are free; F's angle is still required.
The canonical slope guard implies the radian bound by |atan(t)|<=|t|.

Report the actual terminal kind. A sharp-row use does not count as a deep-cylinder
use. Neither helper attaches an original state, reconstructs a whole cover, or
establishes that the complement of its local guard is excluded. All such outer
complements remain separate obligations.

The discovery guard is separate and is never imported by the independent helper.
All replay uses standard-library exact arithmetic with assertions enabled.
