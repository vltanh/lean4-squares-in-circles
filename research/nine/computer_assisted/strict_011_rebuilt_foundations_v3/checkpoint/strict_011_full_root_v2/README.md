## Acceptance boundary

This version exposes the geometry-adapter contract and complete 4/8/2
cover helpers. It does not supply a whole-tree search driver or claim a
complete full-mask exclusion. The enclosing checker must first validate
the full root document, then preserve exact ancestry and every alternative.
The scalar-to-angle inference interface deliberately leaves angles
unchanged. No conditional row theorem or symmetry normalization is
installed. Reuse of optional Gram, four-product or sharp-row helpers must
be separately attached to this root's proved current intervals.

The proof ledger at the preceding published commit
`2c0fb06a27cd568297c2b9320e005eb33ae89cdb` is 222 closed and nine open
registered `001/00` originals, and eight closed and 24 open masks. This
implementation changes neither count. Independent physical/code review
and root acceptance remain required before installation into a proof
search; its first actual numerical use would require fresh exact replay.
