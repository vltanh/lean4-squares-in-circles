## The induction invariant

At each node, every physical configuration in that node's caller has its
original coordinates and frame quantities in the certified state intervals.
It also satisfies every physical path choice already selected. The checker
constructs the root state from the exact frozen root document and reconstructs
each child state from the parent's independently replayed final state.
Serialized initial states must agree exactly with that reconstruction. They
cannot impose an extra unproved interval restriction.

For each printed necessary row, the independently implemented model adapter
reconstructs its coefficients and right-hand side from that same caller and
state. The generic exact arithmetic core checks the literal row, positive
rational multipliers, and every residual correction. If a weighted sum gives
`a.X <= b`, each uneliminated coefficient is paid using the proved absolute
variable bound: `|r.X| <= sum_k |r_k| M_k`. A bound update rounds only outward,
on the core's exact rational grid. All accumulated inherited restrictions are
retained. An interval terminal requires an exact incompatible interval; a
weighted terminal requires a strictly positive exact reserve after paying all
residuals. Numerical points and discovery-status labels provide no premise.

An OPEN record is also replayed. It yields a certified remaining physical
state, never an exclusion. A node is excluded only when the arithmetic checker
returns an independently verified contradiction, or when every child of one
of the complete unions below is excluded.

## The three complete closed unions

For a pair of distinct original squares, an owned separating axis exists among
the two axes of either square. With either sign, these are exactly eight
alternatives `(owner in {i,j}, axis in {0,1}, sign in {-1,+1})`. The checker
requires precisely that set once each and derives each child's physical path
from its parent. Equality cases are included. The model's six auxiliary
products for each selected pair represent the actual common physical frames
and displacement; their exact bounds and McCormick rows are independently
reconstructed by the adapter.

Each original square contains its closed axis-parallel inset square of
half-side `g_i`. Disjoint interiors of the original squares imply disjoint
interiors of these inset squares. Thus at least one of the four closed
alternatives holds: one of the two coordinate differences, with either sign,
is at least `g_i+g_j`. The proxy union contains exactly these four cases. This
is a necessary closed cover of the physical pair, with the original physical
squares and their other constraints still present.

For a rational cut inside the current canonical slope interval of an original
frame, the two restrictions `t_i <= cut` and `t_i >= cut` cover the whole
parent interval. The common face is retained in both children. The
independent angle-child constructor intersects the parent angle and analytic
frame intervals and appends the same literal cut to the physical path. It
does not accept an arbitrary serialized replacement state.

These three finite unions preserve the induction invariant. The traversal
requires every declared record to be reached exactly once from the single
root. Missing or repeated alternatives, repeated children, cycles, and
unreferenced declared records are rejected. An excluded node may not retain
children. Therefore, if the exact traversal has no OPEN leaf, every physical
configuration in the full strict `011/00` caller is excluded.
