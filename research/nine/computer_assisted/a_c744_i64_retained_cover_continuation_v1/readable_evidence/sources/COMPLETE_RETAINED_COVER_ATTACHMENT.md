# Exact leaf continuation of the retained A165 cover

The source is the complete published 165-node cover of component 3 of original
`positive-c744bc031d40ee64`. Its root predicate remains
`y_B + y_D - 2 y_I <= -3/5`. The source has 115 excluded leaves and 17 OPEN
leaves. This construction does not replace that root by the smaller 16/25
domain. All nine originals, 36 original corner predicates, 36 pair predicates,
five marked cones, and all closed faces retain their existing meanings.

The separately accepted whole-original family supplies 414 necessary bounds
on original positions, frame scalars, slopes, Cartesian differences, and
diagonal differences. Its proof combines the complete old complement
exclusions, the physical 16/25 theorem and closed-Q equality blocker, and the
freshly replayed seven-round/813-deduction source. Therefore each endpoint
applies to every state in the retained old component 3 cover without an
additional child restriction. Its one height inequality is supported by the
adapter but is not used as a copied endpoint in this construction.

`extend_retained_cover.py` processes exactly the 17 source OPEN leaves. It
starts each suffix from that leaf's stored final state, retaining its original
initial state and all prior rounds exactly. It attempts one ordinary direct
endpoint round, using positive unit multipliers and the accepted grid. It then
attempts one ordinary propagation round with no printed premises or bound
proposals. Existing exact frame inference and analytic interval intersection
remain in each round. Only the previously accepted effective-angle, center,
scalar, difference, or correlated-diagonal interval terminals can be newly
selected. No optimization, split, new child, or initial-state rebasing occurs.

The output keeps all 165 node indices, parents, depths, restrictions, split
data, child lists, and complete-child flags. Every nonleaf and previously
excluded payload is byte-identical to the published source. The constructor
can hardlink those immutable bytes into a fresh directory; it never opens a
retained payload for writing. Only OPEN leaf payloads can acquire a suffix.
Each new payload is created exclusively and fsynced. The new manifest is
created only after all payloads exist. This is not a multi-file transaction:
any failure leaves an unaccepted partial output, with the source untouched.

`retained_cover_contract.py` checks these byte and attachment facts, including
literal prefix equality and unchanged initial states. These are not arithmetic
acceptance. The new independent adapter delegates every ordinary premise and
terminal to the frozen consequence/four-product adapter. It independently
reconstructs only the new original-wide literals from the accepted source
binding, after checking the unchanged original identity and path prefix.

`replay_retained_cover.py` invokes the frozen bounded-memory complete-cover
reader. That reader freshly checks every retained node and old/new weighted
round, every terminal, every exact child state, and every complete four-way
proxy, eight-way physical SAT, and two-way closed angle union. It visits all
siblings and requires the visited set to equal all 165 nodes. Source and
candidate payload hashes are checked again afterward.

The accepted old complement source proof is reused through the already
reviewed historical provider cache. The complete A1 source and fresh813
evidence are revalidated by identity through the whole-original family;
their arithmetic is not repeated. The wrapper explicitly identifies the
frozen reader's legacy `freshly_replayed_original_complement_consequences`
field as historical reuse. All 165 consumer nodes are freshly checked. This
is native exact consumer evidence, not a cold portable proof.

An OPEN result retains every unexcluded domain explicitly. Even an excluded
component result has zero new original or mask credit here: complete-original
assembly and its publication gates remain separate.
