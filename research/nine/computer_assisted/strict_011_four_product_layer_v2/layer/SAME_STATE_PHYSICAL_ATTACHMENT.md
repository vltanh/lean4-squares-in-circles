## Physical implication on each original square

For one of the nine original unit frames `u=(alpha,beta)`,
`v=(-beta,alpha)`, the original signed corner has squared norm

    K = x²+y²+1/2 + epsilon alpha x+tau alpha y
                     +epsilon beta y-tau beta x.

This uses `alpha²+beta²=1` exactly. Let the four products `(f_j,g_j)` be
`(alpha,epsilon x)`, `(alpha,tau y)`, `(beta,epsilon y)` and
`(beta,-tau x)`. Each factor lies in the independently proved interval for
that same original and current state. Choose either both lower endpoints
or both upper endpoints `(a_j,b_j)` independently for each product. Then

    f_j g_j >= a_j g_j+b_j f_j-a_j b_j,

because `(f_j-a_j)(g_j-b_j)>=0`. Repeated appearances of a frame or center
coordinate cause no difficulty: all four inequalities hold simultaneously
at the same physical values. All 16 patterns are valid rows, not cover
alternatives. Negative beta and negative signed coordinates use their exact
signed interval extrema.

For arbitrary rational `p_x,p_y`, define

    L = 2p_x x+2p_y y+sum_j(a_j g_j+b_j f_j),
    R = 977/256+p_x²+p_y²+sum_j a_j b_j.

The necessary affine row is `L<=R`. Its **full** slack is

    R-L = (1105/256-K) + (x-p_x)²+(y-p_y)²
                          +sum_j(f_j-a_j)(g_j-b_j).

Thus the containment slack is included in addition to the two coordinate
squares and four rectangle products. Strict original containment implies
closed containment, so this necessary row is valid for either permitted
strict-011 caller. It adds no equality assumption, geometric normalization,
new auxiliary variable or selected separating axis.

The fresh controls rebuild all 16 patterns for every original corner on both
callers, including selected-SAT and narrowed-frame states. They compare all
ordinary rows and unchanged auxiliary bounds, expand the full rational
residual, check the accepted grouped subfamily, reject changed or stale
literals and exercise the generic weighted arithmetic with synthetic records.

tree ancestry. Synthetic weights are clearly separate from actual LP use.

returns parameters only. The independent proof attachment never imports it.
Its output has no proof status until exact row reconstruction and a complete
rational weighted certificate pass in the same certified state.
