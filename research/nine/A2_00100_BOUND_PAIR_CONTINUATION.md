## 2. Why inherited bounds may be used on every child

The original full-nine caller, its normalized D-sign root, and its exact
registered path define the parent. Its frame and position intervals are
decoded by the unchanged v14 interpreter. All nine original squares,
corners, pairs, marked cones and strict bits remain hypotheses.

First prove a finite sequence of center-coordinate bounds on the entire
parent. In each round use only previously proved intervals. For valid
rows `a_j.z<=b_j`, bounds `|z_k|<=M_k`, nonnegative rational multipliers
lambda_j and a signed coordinate objective c, put

    r=sum_j lambda_j a_j,  B=sum_j lambda_j b_j.

The original assignment satisfies

    c.z <= B + sum_k M_k |r_k-c_k|.

The printed table verifies that this rational expression is at most its
declared bound. Every deduction in a round uses the same pre-round rows.
Only after all deductions pass are the coordinate intervals intersected.
Induction establishes the final bounds for every point of the parent.
The producer's suggested before/after boxes and numerical assignments
are not proof premises.

Now take a child path in a complete physical tree. It implies its original
parent, so it inherits all those proved coordinate bounds. Intersect the
child's decoded position intervals with them. Keep its decoded angle
intervals and physical choices unchanged. The usual corner, inset,
center-distance, product and analytic rows are valid on this narrower
proved domain. In particular, using narrower intervals in a McCormick
enclosure does not add an unproved position assumption.

The replay implementation supplies exactly this state in a private
function namespace for the unchanged frozen scalar-row routine. It does
not modify the imported original decoder, alter an original frame, reuse
another parent's bounds, or silently strengthen an old historical leaf.
Earlier retained leaves without the explicit inherited-bounds marker
are replayed under their original path conditions.
