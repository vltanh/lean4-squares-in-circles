# Complete Cb882 positive C-primary cover

These appendices prove the [conditional C-primary theorem](../CB882_C_PRIMARY_COMPLETE.md)
using the [finite-cover rules](../CB882_FINITE_COVER_RULES.md).
The original Cb882 hypotheses and the positive C-owned primary separator
are retained throughout. The other two C/D axis alternatives are outside
this conditional theorem.

The complete table has 4,231 case nodes, 5,057 exact contexts and 34,243
labelled rational rows. It contains 60,917 simultaneous bound deductions
and 1,646,512 positive integer weights. There is no open leaf.

Start at [the root](ROOT.md) and node N00000 in [the case table](CASES.md).
The numeric part of a row ID, divided by 512 and rounded down, selects
its ROWS file. The numeric part of a context ID, divided by 128 and
rounded down, selects its CONTEXTS and CERTIFICATES files. File numbers
have three digits. For example, C00128 is in CONTEXTS_001.md and its
row sums are in CERTIFICATES_001.md. The shared rules define every
variable, row family, deduction, case operation and terminal.

The printed data were independently reconstructed: 275,991 context-specific
row instances, all positive sums, and the complete case induction passed.
The proof consists of the displayed rational inequalities and finite
induction; this check introduces no external premise.
