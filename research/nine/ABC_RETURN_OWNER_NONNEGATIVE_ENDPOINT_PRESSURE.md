# An endpoint-owned or shared BC return has nonnegative C pressure

Date: October 25, 2026.

**Status: exact corollary of the previously accepted complete negative-owner
exclusions; independent root full-source and scope review passed on
October 25, 2026. See REVIEW_ABC_ENDPOINT_PRESSURE_2026_10_25.md. This is
a pressure input, not an exclusion of the remaining all-unique ABC family.**

Retain the original H--A--B--C--H cycle and intact H--X--Y--H petal,
with true H4/A2/B2/C2, positive original pair magnitudes, positive total
circle loads at all five boundary bodies, every physical unit, and all

Assume B and C each have exactly one physical circle corner. The other

**Theorem.**

    c_H dot z_C >= 0,

and hence the actual positive circle resultant F_C has nonnegative
H-pressure. No sign of A's pressure is required for this statement.

by A'=C, B'=B, C'=A. This changes names only. H and its intact petal,
the three completion squares, all physical corners and masks, each

degrees remain unchanged. The existing HC interface becomes HA', and
the existing CB interface becomes A'B'. In particular the middle B'
is physically unique, and its other endpoint C' is physically boundary.

The hypotheses of the previously accepted negative-endpoint theorems
therefore hold at A'=C. The common finite selection already contains
the conditions for this reflected ordering; none is newly installed.
