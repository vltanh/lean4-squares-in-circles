# Retained mathematical sources

These 45 source manuscripts support the [roadmap](../PROOF_PLAN.md) and
[partial proof outline](../PROOF.md). They are retained arguments and examples,
not a claim that the unrestricted theorem has been proved. Dated workflow,
status and reproduction remarks belong to the [archived snapshot](../ARCHIVE.md).
References to removed material now point to that snapshot where resolvable.

Begin with the physical two-square cap, the sharp three-square half-plane
cap, the center-cone extraction, and the exact obstruction examples. The
older stratified and signed-chain arguments are retained where later
equality examples use them. Greene's finite-poset theorem remains an explicit
external mathematical dependency of the extraction.
