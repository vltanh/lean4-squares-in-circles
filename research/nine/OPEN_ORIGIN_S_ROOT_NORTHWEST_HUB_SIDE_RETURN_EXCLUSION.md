## 3. The common minimum-m side alternative is impossible

same side, the original N must have N.w>=0. Otherwise
R would be the maximum-w endpoint and Q would lie

Define

    U=u.m=(alpha*z+beta)/s>0,
    V=v.m=(beta*z-alpha)/s.

therefore give

    p/lambda>=alpha*(alpha-beta*z)/(beta+alpha*z).
